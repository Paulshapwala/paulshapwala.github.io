ONGOING · HARDWARE

Off-grid, on the air.

Custom Meshtastic LoRa Node

A custom communication node bringing an nRF52840 controller, RA-01SH LoRa radio and OLED display together on one board. From schematic to soldering to a first message received by a Heltec node.

KiCadnRF52840LoRaMeshtastic
Inside the build +

Working so far: assembled hardware, firmware configuration and a successful test transmission to a second node.

On the bench: battery operation and protection circuitry. Two-way messaging and measured range tests are next; sensor telemetry is a possible extension.

The interesting part: tracing a fault from a symptom back through the schematic and testing each subsystem separately.

ONGOING · ROBOTICS

A small robot.
A lot to understand.

HeRo Robot Modelling & Simulation

Adapting existing HeRo resources into an adjustable CAD assembly and simulation model. Two driven wheels, eight infrared sensor frames, and a closer look at how geometry becomes behaviour.

FreeCADPythonURDFPyBullet
Inside the build +

Working so far: an adjustable FreeCAD assembly, URDF model, structural validation and a short PyBullet movement test.

Next: replace assumed dimensions with measurements and calibrate optical offsets, infrared response and motion before evaluating navigation.

This work builds on the existing HeRo robot platform. The original robot design is not my own.
