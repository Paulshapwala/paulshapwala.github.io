# Paul Shapwala — Portfolio

[Visit the website](https://paulshapwala.github.io/)

Personal portfolio covering mechatronics, embedded systems, robotics, IoT, software and chess.

Built with HTML, CSS and JavaScript. GitHub Pages publishes the main branch from the repository root.

## Update the site

Edit index.html for content, style.css for styling, and script.js for interactions. Project images are stored in assets/.

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

HeRo project content builds on the existing HeRo robot platform; the original robot design is not claimed as my own. Software demonstration screenshots use sample data.
